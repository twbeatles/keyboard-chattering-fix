## English

### Overview

**KeyboardChatteringFix** is an ultra-lightweight, high-performance Windows utility built with pure Rust. It intercepts and filters mechanical keyboard switch bouncing (chatter / double typing) in real time using low-level Windows hooks (`WH_KEYBOARD_LL`) without requiring administrator privileges or invasive DLL injection.

Featuring a native Windows 11 Fluent Card interface, real-time diagnostic telemetry, per-key threshold suggestions, optional mouse-button filtering, a convenient cleaning mode, and an Ed25519 cryptographically signed auto-update pipeline, KeyboardChatteringFix keeps your typing clean as a single small native executable.

---

### Key Capabilities

#### 1. Zero-Latency Filtering Engine
- **OS-Level Filtering**: Intercepts chattered keystrokes at the OS hook layer, on a dedicated hook thread, before applications receive them.
- **Precise Gap Measurement**: Gaps are measured with the high-resolution monotonic clock (`QueryPerformanceCounter`), so they do not depend on the 15.6 ms scheduler tick.
- **Synthetic Input Protection (`LLKHF_INJECTED`)**: Recognizes artificial input generated by AutoHotkey, IMEs, screen readers, and remote desktop tools, preventing macro and typing glitches.
- **IME-Safe**: `VK_PACKET`/`VK_PROCESSKEY` events (different characters sharing one code) are never treated as chatter, even with injected-input filtering turned off.
- **Hardware-Accurate Debounce Modes**:
  - `Release` (Default): Measures elapsed time from key release (`Up`) to the next press (`Down`). Highly robust against prolonged holds.
  - `Press`: Measures interval between consecutive accepted presses (`Down` to `Down`).
- **Auto-Repeat Preservation**: Holding a key forwards continuous down events naturally without false-positive blocks — including after a contact bounce in the middle of a hold, where the next auto-repeat resumes the key instead of being blocked as more chatter.
- **Mouse Button Chatter (optional)**: Left / right / middle / side buttons can be filtered too (a single click registering as a double-click). The mouse hook is installed only while this is on.
- **Release Delay (optional, `iReleaseDeferMs`)**: Holds each release of a held key or button back for a few ms. If the contact bounces back in that time, applications never see the key released — no more dropped movement keys or broken mouse drags in games.
- **Physical-Key Accuracy**: Keys that share a code (main Enter vs. numpad Enter, arrow cluster vs. numpad arrows) are timed separately.
- **Microsecond Glitch Filter (`min_chatter_ms`)**: Filters out 0ms-class electrical glitches and buggy hardware events cleanly.

#### 2. Native Windows 11 Fluent UI
- **Immersive Dark / Light Theme Sync**: Dynamically detects the system theme (`AppsUseLightTheme`) and applies dark titlebars (`DWMWA_USE_IMMERSIVE_DARK_MODE`).
- **Rounded Corners & Dark Titlebar**: Native Windows 11 aesthetics with rounded window geometry (`DWMWA_WINDOW_CORNER_PREFERENCE = ROUND`).
- **Tabbed Layout + Menu Bar**: Home / History / Keys & Mouse / Settings / Advanced tabs, plus File / Tools / Help menus (update check, About, open settings folder).
- **Automatic Language**: Follows your Windows language — Korean on a Korean system, English everywhere else — and can be pinned to Korean or English in Settings. The language list is a registry, so adding a language is a small, compiler-guided change (see `src/i18n/language.rs`).
- **Toggle Switches & Owner-Drawn Controls**: Windows 11-style switches and buttons that stay readable in both dark and light themes.
- **DPI-Aware, Crisp Text**: Layout and fonts scale with the display (125% / 150%) instead of being bitmap-stretched.
- **Double-Buffered Rendering**: Smooth rendering with zero flickering during real-time telemetry updates.

#### 3. Real-Time Telemetry & Diagnostics
- **Live Metrics**: Real-time display of total keystrokes, chatter intercepted count, and chatter ratio (%).
- **Recent Blocked Key Badge**: Displays the exact virtual key name and observed gap in milliseconds (`Last blocked: Space (32ms)`).
- **Top Problematic Key Detection**: Tracks keystrokes per key (0–255) to automatically diagnose your most degraded switch and its failure rate.
- **History Tab**: Filter the event log by *blocked only* / *all input* / *per-key summary* and by key name; blocked rows are highlighted with their gap in ms. Double-click a per-key row to change that key's threshold. The **Clear key stats** button on the Keys & Mouse tab forgets one key's counters after you replace its switch.
- **Threshold Suggestions**: For every key, the gaps between release and the next press are collected in a small histogram. When chatter (a few ms) and your real presses (tens of ms) are separated, the Keys & Mouse tab suggests a threshold just above the chatter; when they overlap, it tells you the switch needs cleaning or replacing.
- **100+ Virtual Key Name Map**: Human-readable names for media keys, volume controls, numpad, F1–F24, and navigation keys.

#### 4. Helpful Tools & Customization
- **🧹 Keyboard Cleaning Mode**: Locks all key presses so you can clean and wipe keycaps safely. Press `Enter` or click **Finish cleaning** to unlock; it also ends by itself after 5 minutes (`iCleaningTimeoutMin`).
- **🔊 Custom Audio (.wav) & Tester**: Play custom `.wav` sounds or system beeps on chatter detection, complete with an in-app test button.
- **⚙️ Windows Keyboard Control Panel**: One-click shortcut to launch Windows Keyboard Properties (`control.exe keyboard`) to calibrate repeat delays and rates.
- **Per-Key Custom Overrides**: Keep a low global threshold (e.g. 50ms) and give erratic keys or mouse buttons their own, in the **Keys & Mouse** tab (applied and saved at once) or in the settings file.
- **Window Close Customization (`bCloseToTray`)**: Choose whether the close button (X) minimizes to tray or exits completely.
- **⌨️ Global Hotkeys**: Toggle protection or start cleaning mode from anywhere (e.g. `Ctrl+Alt+F12`, Advanced tab). Menus show the registered hotkeys.
- **🎮 Automatic Pause**: Pause while listed apps (`game.exe; obs64.exe`) or any full-screen app is in front. The badge shows "◐ Paused" and the Home tab says why.
- **🛡️ Administrator Windows**: The Home tab warns when a window running as administrator is in front (its input is out of reach). **Tools > Run as administrator** covers it; while elevated, **Start as administrator at sign-in** registers a scheduled task.
- **🩺 Hook Watchdog**: If Windows silently drops the keyboard hook, the program notices (a probe while you are active) and reinstalls it.
- **📤 Export / Import**: History as CSV (opens in Excel), settings export and import (this PC's statistics are kept).
- **💼 Portable Mode**: Put a `settings.ini` next to the executable to keep settings there instead of `%APPDATA%`.
- **Tray State**: The tray icon turns gray while protection is paused or off.

#### 5. Secure Ed25519 Auto-Update Pipeline
- **Cryptographic Verification**: Auto-update manifests (`update.json`) are verified using Ed25519 digital signatures and SHA-256 binary digests.
- **Fail-Safe In-Place Replacement**: The update is staged and verified in `%TEMP%`; the companion helper (`kcfix-updater.exe`) then swaps the program in its install folder and automatically rolls back if the new version fails to start.

### Configuration Guide

Settings are saved in `%APPDATA%\KeyboardChatteringFix\settings.ini` (or in `settings.ini` next to the executable in portable mode):

```ini
[KeyboardChatteringFix]
iThreshold=50          # Global chatter threshold in ms (1–1000)
bFilterEnabled=1       # Enable (1) or disable (0) chatter filtering
bPlaySound=0           # Play notification sound on block (1=On, 0=Off)
lpSoundFile=           # Path to custom .wav file (empty = default beep)
bMinimizeOnLaunch=0    # Minimize to tray on startup (1=On, 0=Off)
bCloseToTray=1         # Minimize to tray on window close (1=On, 0=Exit)
bRecordAllKeypress=0   # Telemetry log: 1=record all keys, 0=blocked chatter only
iLogLimit=100          # Maximum in-memory log buffer size
sLanguage=auto         # Interface language: "auto" (default: Korean on a Korean Windows, otherwise English), "ko" or "en"
sMeasureFrom=release   # Measurement baseline: "release" or "press"
iMinChatterMs=0        # Ignore chatter intervals below this limit (ms)
bExcludeInjected=1     # Ignore synthetic events from AHK/IME/macros (1=On)
bFilterMouse=0         # Also filter mouse button chatter (1=On)
iReleaseDeferMs=0      # Hold releases of held keys back this long (0=off, 0–100; 20–40 typical)
sAutoDisableApps=      # Pause while these apps are in front, e.g. "game.exe; obs64.exe"
bAutoDisableFullscreen=0 # Pause while any full-screen app is in front (1=On)
sHotkeyToggle=         # Hotkey that toggles protection, e.g. "Ctrl+Alt+F12" (empty = none)
sHotkeyCleaning=       # Hotkey that starts cleaning mode, e.g. "Ctrl+Alt+F11"
iCleaningTimeoutMin=5  # Cleaning mode ends by itself after N minutes (0 = never)

# Per-key overrides: key.<HEX_VIRTUAL_KEY>=<MILLISECONDS>
key.48=120             # Custom 120ms threshold for 'H' key (0x48)
key.20=80              # Custom 80ms threshold for Spacebar (0x20)
key.01=30              # Custom 30ms threshold for the left mouse button
```

The **Keys & Mouse** tab edits the same `key.XX` lines and writes them immediately; edits made directly in the file while the program runs are kept.
A `#` or `;` after a space starts a comment, as in the sample (the sound path keeps everything). Files saved in the system code page instead of UTF-8 are read too. A start at sign-in always goes to the tray, whatever `bMinimizeOnLaunch` says.

### Tuning the Threshold

1. Start with the default (50 ms, measured from key release). Chatter gaps are usually a few to about 20 ms; common guides suggest starting between 20 and 50 ms.
2. Use the keyboard normally for a while, then open **Keys & Mouse**. Keys that chattered are listed with a **Suggested** value; select one and press **Apply**.
3. If double typing persists on one key, raise only that key. If fast intentional repeats (e.g. `ll`, `ee`) get swallowed, lower the global value.
4. "Check switch" means bounces and real presses overlap, so no threshold can separate them. Clean (compressed air / contact cleaner) or replace the switch.

### Known Limitations / FAQ

- **Elevated windows**: a non-elevated low-level hook does not see input going to windows that run as administrator (Task Manager, admin terminals, some installers and game launchers), because of UIPI. The Home tab tells you when such a window is in front; **Tools > Run as administrator** covers it, and **Start as administrator at sign-in** keeps it that way.
- **Secure desktop**: the sign-in screen, the lock screen, and UAC prompts are out of reach of any user-space filter.
- **Start as administrator at sign-in — where the program lives matters**: the task starts this file with administrator rights at every sign-in. If the file sits in a folder you can change without administrator rights (a portable folder, Scoop, winget), any program running in your account could replace it and gain those rights, so the program warns before turning this on. Keep it under `Program Files` to use this safely. While running as administrator, in-app updates are turned off for the same reason (exit, start normally, then update).
- **Games / anti-cheat**: this tool blocks input through a system-wide hook, which some online games' anti-cheat may object to. List the game in **Excluded apps** (Settings > Auto pause) (or turn on the full-screen pause) so protection steps aside while it is in front.
- **Mouse drags / held keys**: a bounce while *holding* a button or key arrives as a release followed by a press. Without a release delay the press is blocked but the release already reached the application, so a drag can drop; set **Release delay** (20–40 ms) to fix it.
- **Firmware first**: if your keyboard runs QMK/VIA, raising its `DEBOUNCE` value fixes chatter at the source. A software filter treats the symptom, and a failing switch tends to get worse.
- **Remote desktop / IME / macros**: their input is injected and passes through untouched while "Leave input sent by other programs alone" is on (the default).
- **If the window ever stops responding**: `%TEMP%\kcfix-diag.log` records slow UI ticks and hook restarts for diagnosis. The filter keeps running on its own thread while the window is stuck.

### 소개

**KeyboardChatteringFix**는 순수 Rust로 개발된 초경량 고성능 Windows 키보드 채터링(스위치 바운스 / 이중 입력) 방지 유틸리티입니다. 기계식 및 접점식 키보드의 스위치 노후화나 접점 결함으로 인해 키가 빠르게 연타되는 현상을 저수준 키보드 훅(`WH_KEYBOARD_LL`)을 통해 실시간으로 감지하고 차단합니다.

### 핵심 기능 및 특장점

#### 1. 마이크로초 단위 초저지연 필터링 엔진
- **OS 레벨 즉각 차단**: 키 신호가 애플리케이션으로 넘어가기 전 윈도우 훅 레이어(전용 훅 스레드)에서 바운스 신호만 가로채 드롭합니다.
- **정밀한 간격 측정**: 간격은 고해상도 단조 시계(`QueryPerformanceCounter`)로 재므로 Windows 기본 스케줄러 틱(15.6ms)에 좌우되지 않습니다.
- **가상/합성 입력 보호 (`LLKHF_INJECTED`)**: AutoHotkey, 한영 변환(IME), 원격 데스크톱 등 소프트웨어가 생성한 신호를 감지하여 건드리지 않습니다.
- **IME 안전**: 서로 다른 글자가 한 코드로 들어오는 `VK_PACKET`/`VK_PROCESSKEY`는 합성 입력 제외를 꺼도 채터링으로 보지 않습니다.
- **상황별 채터링 측정 모드 (`MeasureFrom`)**:
  - `Release` (기본값): 키를 뗀(`Up`) 시점부터 다음 눌린(`Down`) 시점까지의 시간을 측정하여 느린 릴리스에서도 완벽하게 보호합니다.
  - `Press`: 이전 정상 입력(`Down`) 시점부터 다음 입력 시점까지의 간격을 측정합니다.
- **오토리핏(연속 입력) 보존**: 키를 누르고 있을 때 발생하는 연속 Down 입력은 차단하지 않고 정상 전달합니다. 누르고 있는 도중 접점이 한 번 튀어도, 이어지는 오토리핏은 채터링으로 막지 않고 키 입력을 바로 이어갑니다.
- **마우스 버튼 채터링 차단 (선택)**: 왼쪽·오른쪽·가운데·옆 버튼의 "한 번 클릭했는데 더블클릭" 현상도 막을 수 있습니다. 켜 둔 동안에만 마우스 훅을 설치합니다.
- **떼기 확인 시간 (선택, `iReleaseDeferMs`)**: 누르고 있는 키·버튼의 뗌을 몇 ms 보류합니다. 그 사이 접점이 다시 붙으면 앱은 키가 떼어진 것을 보지 못하므로, 게임 이동 키 끊김이나 마우스 드래그 끊김이 사라집니다.
- **물리 키 단위 판단**: 메인 Enter와 숫자패드 Enter, 방향키와 숫자패드 방향키처럼 같은 코드를 쓰는 키를 따로 잽니다.
- **하드웨어 글리치 필터 (`min_chatter_ms`)**: 0ms 급 드라이버 오류나 기기 이상 입력을 필터링 예외로 지정할 수 있습니다.

#### 2. Windows 11 모던 Fluent UI 대시보드
- **시스템 테마 실시간 동기화**: Windows 다크/라이트 모드(`AppsUseLightTheme`)를 감지하여 다크 타이틀바(`DWMWA_USE_IMMERSIVE_DARK_MODE`)와 테마를 자동 적용합니다.
- **Windows 11 둥근 창 모서리**: `DWMWA_WINDOW_CORNER_PREFERENCE = ROUND`로 윈도우 11 특유의 미려한 둥근 창을 제공합니다.
- **탭 + 메뉴 바 구성**: 홈 / 기록 / 키·마우스 / 설정 / 고급 탭과 파일 / 도구 / 도움말 메뉴(업데이트 확인, 프로그램 정보, 설정 폴더 열기)를 제공합니다.
- **언어 자동 인식**: Windows 언어를 따라 한국어 Windows에서는 한국어, 그 외에는 영어로 시작하며, 설정에서 한국어/영어로 고정할 수도 있습니다. 언어 목록이 한 곳(`src/i18n/language.rs`)에 모여 있어 새 언어를 추가하기 쉽습니다.
- **토글 스위치와 쉬운 용어**: Windows 11 스타일 스위치·버튼을 직접 그려 다크/라이트 모드 모두에서 또렷하며, 설정 이름을 기술 용어 대신 쉬운 말로 설명합니다.
- **고해상도(DPI) 대응**: 125%/150% 배율에서도 글자가 흐려지지 않도록 레이아웃과 글꼴을 배율에 맞춰 그립니다.
- **더블 버퍼링(Double Buffering)**: 실시간 수치 갱신이나 창 조작 시 화면 깜빡임(Flicker)이 전혀 없습니다.

#### 3. 실시간 텔레메트리 및 스위치 수명 진단
- **실시간 통계 그리드**: 총 타건 수, 차단된 채터링 횟수, 채터링 발생 비율(%)을 타일 카드로 시각화합니다.
- **최근 차단 키 알림 칩**: 가장 최근 차단된 키와 실제 바운스 간격(`최근 차단: Space (32ms 간격)`)을 실시간 표시합니다.
- **최다 불량 키(Top Chatter Key) 자동 진단**: 256개 가상키별 누적 타건수와 차단수를 분석하여 가장 상태가 나쁜 스위치와 불량 비율을 자동 추적합니다.
- **기록 탭 (필터 보기)**: "막은 입력만 / 모든 입력 / 키별 통계" 보기와 키 이름 검색으로 차단 이력을 걸러 볼 수 있으며, 막은 입력은 간격(ms)과 함께 강조 표시됩니다. 키별 통계 행을 두 번 클릭하면 그 키의 기준을 바로 바꿀 수 있습니다. 스위치를 교체한 뒤에는 [키·마우스] 탭의 **이 키 통계 지우기** 버튼으로 그 키의 누적 기록을 지울 수 있습니다.
- **권장 기준 자동 계산**: 키마다 "뗀 순간 → 다음 누름" 간격을 작은 히스토그램으로 모읍니다. 채터링(수 ms)과 평소 입력(수십 ms) 사이가 비어 있으면 [키·마우스] 탭이 채터링 바로 위의 기준을 권장하고, 둘이 겹치면 스위치 청소·교체를 안내합니다.
- **100+개 전체 가상키 이름 매핑**: 미디어 키, 볼륨, 넘패드, F1~F24, 방향키 등을 직관적인 이름으로 출력합니다.

#### 4. 유용한 도구 및 편의 기능
- **🧹 키보드 청소 모드 (Clean Keyboard)**: 키캡을 닦을 때 키가 잘못 입력되지 않도록 모든 키 누름을 일시 차단합니다. 청소 후 `Enter` 키를 누르거나 **청소 끝내기** 버튼을 클릭하면 즉시 잠금이 해제되고, 잊어도 5분 뒤 자동으로 끝납니다(`iCleaningTimeoutMin`).
- **🔊 커스텀 알림음 (.wav) & 사운드 테스트**: 채터링 차단 시 기본 비프음 외에 사용자가 지정한 `.wav` 효과음을 재생할 수 있으며, UI에서 즉시 테스트 청취가 가능합니다.
- **⚙️ Windows 키보드 설정 바로가기**: `control.exe keyboard`를 원클릭으로 호출하여 키 반복 속도 및 지연 시간을 조율합니다.
- **키별 개별 임계값 (Per-Key Override)**: 전체 키에는 50ms 등 낮은 전역값을 두고, 말썽인 키나 마우스 버튼에만 따로 기준을 줄 수 있습니다. [키·마우스] 탭에서 바로 적용·저장되며, 설정 파일로도 지정할 수 있습니다.
- **창 닫기 동작 커스터마이징 (`bCloseToTray`)**: 창 닫기(X 버튼) 시 트레이로 최소화할지, 완전 종료할지 선택 가능합니다.
- **⌨️ 전역 단축키**: 어디서든 보호 켜기/끄기, 청소 모드 시작(예: `Ctrl+Alt+F12`, 고급 탭). 메뉴에 등록된 단축키가 표시됩니다.
- **🎮 자동 일시 중지**: 지정한 프로그램(`game.exe; obs64.exe`)이나 전체 화면 앱이 앞에 있으면 잠시 멈춥니다. 상태 표시가 "◐ 잠시 멈춤"으로 바뀌고 홈 화면에 이유가 나옵니다.
- **🛡️ 관리자 권한 창 대응**: 관리자 권한 창이 앞에 있으면(그 창의 입력은 걸러지지 않음) 홈 화면에 안내합니다. **도구 > 관리자 권한으로 다시 실행**으로 해결하고, 관리자 권한 실행 중에는 **로그인할 때 관리자 권한으로 자동 실행**(작업 스케줄러)을 켤 수 있습니다.
- **🩺 훅 감시**: Windows가 키보드 훅을 알림 없이 떼어 내면 감지해(사용 중일 때만 확인 신호를 보냄) 다시 설치합니다.
- **📤 내보내기 / 가져오기**: 기록을 CSV로(엑셀에서 바로 열림), 설정 내보내기·가져오기(이 PC의 통계는 유지).
- **💼 포터블 모드**: 실행 파일 옆에 `settings.ini`를 두면 `%APPDATA%` 대신 그 파일을 씁니다.
- **트레이 상태 표시**: 보호가 꺼졌거나 잠시 멈추면 트레이 아이콘이 회색으로 바뀝니다.

#### 5. Ed25519 서명 기반 안전한 자동 업데이트 파이프라인
- **암호학적 서명 검증**: GitHub Releases의 `update.json` 매니페스트를 Ed25519 공개키와 SHA-256 해시로 이중 검증하여 변조를 완벽히 차단합니다.
- **안전한 인플레이스 교체 및 자동 롤백**: 전용 헬퍼(`kcfix-updater.exe`)가 앱 종료를 기다려 안전하게 교체하며, 교체 실패 시 자동으로 이전 버전으로 롤백 복구합니다.

### 설정 파일 상세 안내

설정 파일은 `%APPDATA%\KeyboardChatteringFix\settings.ini`(포터블 모드에서는 실행 파일 옆 `settings.ini`)에 보존됩니다:

```ini
[KeyboardChatteringFix]
iThreshold=50          # 전역 채터링 임계값(ms). 이 시간 내의 재입력은 차단됨
bFilterEnabled=1       # 채터링 필터 활성화 (1=켜짐, 0=꺼짐)
bPlaySound=0           # 차단 시 알림음 재생 여부 (1=켜짐, 0=꺼짐)
lpSoundFile=           # 사용자 지정 .wav 사운드 파일 경로 (비우면 기본 비프음)
bMinimizeOnLaunch=0    # 실행 시 트레이로 최소화 (1=켜짐, 0=꺼짐)
bCloseToTray=1         # 창 닫기(X) 시 트레이로 최소화 (1=켜짐, 0=완전 종료)
bRecordAllKeypress=0   # 모든 키 누름 로깅 (1=모든 키, 0=차단된 채터링만)
iLogLimit=100          # 메모리 내 실시간 로그 보관 수
sLanguage=auto         # 인터페이스 언어 ("auto"=기본값: 한국어 Windows면 한국어, 그 외는 영어 / "ko" / "en")
sMeasureFrom=release   # 간격 측정 기준 ("release" 또는 "press")
iMinChatterMs=0        # 이 값보다 작은 간격은 결함 입력으로 간주하여 통과
bExcludeInjected=1     # 외부 매크로/IME 합성 입력 제외 (1=권장)
bFilterMouse=0         # 마우스 버튼 채터링도 막기 (1=켜짐)
iReleaseDeferMs=0      # 누르고 있는 키의 뗌을 이만큼 보류 (0=끔, 0~100, 보통 20~40)
sAutoDisableApps=      # 이 프로그램이 앞에 있으면 잠시 멈춤 (예: "game.exe; obs64.exe")
bAutoDisableFullscreen=0 # 전체 화면 앱이 앞에 있으면 잠시 멈춤 (1=켜짐)
sHotkeyToggle=         # 보호 켜기/끄기 단축키 (예: "Ctrl+Alt+F12", 비우면 없음)
sHotkeyCleaning=       # 청소 모드 단축키 (예: "Ctrl+Alt+F11")
iCleaningTimeoutMin=5  # 청소 모드 자동 종료(분, 0=끄지 않음)

# 키별 개별 임계값 설정: key.<16진수_가상키코드>=<밀리초>
key.48=120             # 'H' 키(0x48)에만 120ms 적용
key.20=80              # 스페이스바(0x20)에만 80ms 적용
key.01=30              # 마우스 왼쪽 버튼에만 30ms 적용
```

[키·마우스] 탭은 같은 `key.XX` 줄을 편집하며 바로 파일에 씁니다. 프로그램 실행 중에 파일을 직접 고친 내용도 보존됩니다.
위 예시처럼 공백 뒤의 `#`·`;`부터는 주석으로 무시합니다(사운드 경로는 그대로 둠). UTF-8이 아닌 시스템 코드 페이지로 저장한 파일도 읽습니다. 로그인할 때 자동으로 시작되면 `bMinimizeOnLaunch`와 관계없이 항상 트레이로 시작합니다.

### 차단 기준 맞추기

1. 기본값(50ms, 키를 뗀 순간부터)으로 시작하세요. 채터링 간격은 보통 수 ms~20ms 정도이고, 일반적인 가이드는 20~50ms에서 시작하기를 권합니다.
2. 한동안 평소처럼 쓴 뒤 [키·마우스] 탭을 열면, 튄 적이 있는 키가 **권장** 값과 함께 나옵니다. 키를 고르고 **적용**을 누르세요.
3. 특정 키만 계속 두 번 입력되면 그 키만 올리세요. 일부러 빠르게 누른 연타(`ll`, `ee` 등)가 씹히면 전체 기준을 낮추세요.
4. "스위치 점검"은 튄 입력과 평소 입력의 간격이 겹친다는 뜻으로, 어떤 기준으로도 둘을 구분할 수 없습니다. 에어 블로워·접점 부활제로 청소하거나 스위치를 교체하세요.

### 알려진 한계 / FAQ

- **관리자 권한 창**: 관리자 권한 없이 실행된 저수준 훅은 관리자 권한으로 실행된 창(작업 관리자, 관리자 터미널, 일부 설치 프로그램·게임 런처)으로 가는 입력을 보지 못합니다(UIPI). 그런 창이 앞에 있으면 홈 화면에 안내가 나오며, **도구 > 관리자 권한으로 다시 실행**으로 해결하고 **로그인할 때 관리자 권한으로 자동 실행**으로 유지할 수 있습니다.
- **보안 데스크톱**: 로그인 화면, 잠금 화면, UAC 확인 창에는 사용자 공간 필터가 닿지 않습니다.
- **로그인할 때 관리자 권한으로 자동 실행 — 프로그램 위치가 중요합니다**: 이 작업은 매 로그인마다 이 파일을 관리자 권한으로 실행합니다. 파일이 관리자가 아니어도 바꿀 수 있는 폴더(포터블 폴더, Scoop, winget)에 있으면, 이 계정에서 실행된 다른 프로그램이 파일을 바꿔치기해 관리자 권한을 얻을 수 있습니다. 그래서 켜기 전에 경고가 나오며, 안전하게 쓰려면 `Program Files` 아래에 두세요. 같은 이유로 관리자 권한으로 실행 중일 때는 앱 안에서 업데이트하지 않습니다(종료 후 일반 권한으로 실행해 업데이트).
- **게임 / 안티치트**: 이 프로그램은 시스템 전역 훅으로 입력을 막기 때문에 일부 온라인 게임의 안티치트가 문제 삼을 수 있습니다. 게임을 [설정] 탭 자동 일시 중지의 **제외할 프로그램**에 넣거나 전체 화면 일시 중지를 켜면, 게임이 앞에 있는 동안 보호가 비켜 줍니다.
- **마우스 드래그 / 누르고 있는 키**: 버튼이나 키를 *누르고 있는 중*의 바운스는 "뗌 → 누름"으로 들어옵니다. 떼기 확인 시간이 0이면 누름은 막지만 뗌은 이미 앱에 전달되어 드래그가 끊길 수 있습니다. **떼기 확인 시간**을 20~40ms로 두면 해결됩니다.
- **펌웨어 우선**: QMK/VIA 키보드라면 펌웨어의 `DEBOUNCE` 값을 올리는 것이 근본적인 해결입니다. 소프트웨어 필터는 증상을 막을 뿐이고, 고장 나는 스위치는 점점 나빠지는 경향이 있습니다.
- **원격 데스크톱 / IME / 매크로**: 이들의 입력은 합성 입력이라 "다른 프로그램이 보낸 입력은 건드리지 않기"(기본값)가 켜져 있으면 그대로 통과합니다.
- **창이 응답하지 않을 때**: `%TEMP%\kcfix-diag.log`에 느린 UI 틱과 훅 재시작 기록이 남아 원인 파악에 쓸 수 있습니다. 창이 멈춰도 필터는 전용 스레드에서 계속 동작합니다.

  Scoop으로 설치했다면 `scoop update keyboard-chattering-fix`로 업데이트하며, 앱의 업데이트 확인도 그렇게 안내합니다.
- **winget**: `packaging/winget/`에 매니페스트를 준비해 두었습니다(아직 `winget-pkgs`에 제출하지 않음).

### 명령줄

| 옵션 | 동작 |
|---|---|
| `--version` / `-V` | 버전 출력 |
| `--check-update` | 새 릴리스 확인 |
| `--check-helper` | 프로그램 옆 업데이트 헬퍼 사용 가능 여부(정상이면 종료 코드 0) |
| `--check-language` | 이 PC에서 "자동"이 고르는 언어 표시 |

### 업데이트 확인

- 창 메뉴의 **도움말 > 업데이트 확인**, 또는 시스템 트레이 아이콘 우클릭 → **업데이트 확인**으로 새 버전을 확인할 수 있습니다.
- 터미널에서는 `KeyboardChatteringFix.exe --check-update`로 확인할 수 있습니다.
- `KeyboardChatteringFix.exe --check-helper`로 프로그램 옆의 업데이트 헬퍼가 사용 가능한지 확인할 수 있습니다(정상이면 종료 코드 0).
- 업데이트 파일은 Ed25519 서명으로 검증되며, 교체는 `kcfix-updater.exe`(앱과 같은 폴더)가 수행합니다. 배포 절차는 [docs/UPDATE.md](docs/UPDATE.md)를 참고하세요.
- 프록시 환경: `HTTPS_PROXY`/`ALL_PROXY`를 따르고, 없으면 Windows에 수동으로 설정한 프록시를 씁니다(자동 프록시 스크립트는 지원하지 않음).
